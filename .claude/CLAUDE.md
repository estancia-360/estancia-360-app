## Service Pattern — CRITICAL
Full reference: `src/modules/users/services/users.service.ts`

```typescript
// DTO class is ALWAYS the first argument
findAll<T>(dto, params)                          // → PaginationResponseDto<T>
findOne<T>(dto, where, { throwException: false}) // → T | null
findOne<T>(dto, where, options?)                 // → T  (throws if missing)
findOneById<T>(dto, id, options?)
// Add findOneBy<Field> only when that field exists on this entity

create<T>(returnDto, createDto, options?)        // → T
update<T>(returnDto, id, updateDto, options?)    // → T
remove(id, options?)                             // void
```
- Existence check → `rawRepo.existsBy(where)` (SELECT 1, no DTO overhead)
- Create → `repo.create()` + explicit field assignment (no spread)
- Return → `new DtoRepository(repo).findOne({ dto: returnDto, where: { id } })` (transaction-safe)
- All in `src/shared/CLAUDE.md` → DtoRepository, MutationOptions, FindOptions, pagination

## Controller Pattern — CRITICAL
Full reference: `src/modules/users/controllers/users.controller.ts`

```typescript
import { ApiNotFound, ApiUnauthorized, ApiConflict } from 'src/shared/utils/swagger';
import { AdminUp, RootOnly, UserUp } from 'src/app/auth/decorators';
/**
 * Error dictionary: X_NOT_FOUND 404, X_ALREADY_EXISTS 409
 *   INVALID_TOKEN 401, INSUFFICIENT_PERMISSIONS 403
 */
@ApiTags('...') @ApiBearerAuth('access-token') @Controller('...')
export class XController {
    @Get(':id') @AdminUp()
    @ApiOperation({ summary: '...', description: '...' })
    @ApiOkResponse({ type: XDto })
    @ApiNotFound({ code: 'X_NOT_FOUND', message: 'X not found.' })
    @ApiUnauthorized({ code: 'INVALID_TOKEN', message: 'Invalid or expired token.' })
    async findOne(@Param('id', ParseIntPipe) id: number): Promise<XDto> {
        return await this.service.findOneById(XDto, id);
    }
}
```
- `async` + `return await` on every method
- Error decorators are variadic: `@ApiNotFound(err1, err2)` shows dropdown in Swagger for multiple codes
- `'access-token'` = security scheme name from `src/config/helpers/swagger.ts`
- Full swagger util reference → `src/shared/CLAUDE.md`

## Exception Pattern
All exceptions → `{ statusCode, error, message, path, timestamp }` via HttpExceptionFilter.
The `error` field (SCREAMING_SNAKE_CASE) is what the frontend uses to distinguish same-status errors.

```typescript
export class XNotFoundException extends NotFoundException {
    constructor() { super({ message: 'X not found.', error: 'X_NOT_FOUND' }); }
}
```
- One class per exception, one file per class, barrel in `exceptions/index.ts`
- **Never** throw NestJS built-ins inline in services — always use the exception class
